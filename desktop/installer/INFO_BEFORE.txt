Welcome to Scizor Desktop Setup!

Scizor Desktop is an AI-powered productivity tool that enhances your workflow with intelligent features including:

• AI-powered text enhancement and generation
• Smart clipboard management
• Quick note-taking capabilities
• Customizable hotkeys for rapid access
• Text-to-speech functionality

SYSTEM REQUIREMENTS:
• Windows 10 or later (64-bit)
• 4 GB RAM (8 GB recommended)
• 500 MB available disk space
• Internet connection for AI features

BEFORE INSTALLATION:
• Close all running applications
• Ensure you have administrator privileges if installing for all users
• Disable antivirus temporarily if installation fails

Thank you for installing Scizor Desktop!

ABOUT SCIZOR DESKTOP:
Scizor Desktop is an advanced AI-powered productivity application designed to enhance your workflow with intelligent text processing, clipboard management, and quick access features.

FEATURES:
• AI Text Enhancement - Improve and optimize your text with AI
• Smart Clipboard - Advanced clipboard management with history
• Quick Notes - Fast note-taking with AI assistance
• Hotkey Support - Customizable keyboard shortcuts
• Text-to-Speech - Convert text to speech with high-quality voices
• Secure Authentication - Protected access to AI features

GETTING STARTED:
1. Launch the application from Start Menu or Desktop
2. Complete the authentication setup
3. Configure your preferences in Settings
4. Enable hotkeys for quick access
5. Start using AI-powered features!

SYSTEM REQUIREMENTS:
• Windows 10 or later (64-bit)
• 4 GB RAM minimum (8 GB recommended)
• 500 MB disk space
• Internet connection for AI features
